Detailed Description

A pair of vectors using the wire format formerly provided by yarp::os::PortablePair<yarp::sig::Vector, yarp::sig::Vector>.

PortablePair was removed in YARP 4. Keeping the serialization local makes learningMachine compatible with both existing ports and recorded data.
