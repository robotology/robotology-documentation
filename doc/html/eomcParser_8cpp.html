A map of control output types from configuration strings to their enum values and descriptions.

NOTE: in this map the velocity output is mapped to eomc_ctrl_out_type_vel_pwm, and in the parse of velocitydirect control there is a check for the output required. If it is current, then the parse changes the output type to eomc_ctrl_out_type_vel_cur, otherwise it remains eomc_ctrl_out_type_vel_pwm.
