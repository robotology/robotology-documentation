\hypertarget{md_icub-main_2src_2libraries_2icubmod_2embObjMotionControl_2YARP4__Velocity__Control__Guide}{}\label{md_icub-main_2src_2libraries_2icubmod_2embObjMotionControl_2YARP4__Velocity__Control__Guide}\index{YARP 4 Motor Control Modes and Velocity Control@{YARP 4 Motor Control Modes and Velocity Control}}

This document describes the motor-\/control extensions introduced during the work related to \href{https://github.com/robotology/icub-firmware/issues/615}{\texttt{robotology/icub-\/firmware\#615}}.

The main goals are\+:


\begin{DoxyItemize}
\item Introduce a dedicated {\bfseries{Velocity Direct}} control mode.
\item Allow velocity control to generate either\+:
\begin{DoxyItemize}
\item a direct {\bfseries{PWM}} command, or
\item a {\bfseries{current}} reference processed by the internal current loop.
\end{DoxyItemize}
\item Make the different combinations of high-\/level control modes and low-\/level outputs configurable.
\item Update the YARP interfaces, configuration files, parser, communication protocol, EMS firmware, and 2FOC firmware accordingly.
\item Provide clearer PID configuration and descriptions in {\ttfamily yarpmotorgui}.
\item Introduce the {\ttfamily Feed\+Foward}parameter in the {\ttfamily Velocity Direct} with inner current control.
\item Configure Kbemf in as motor parameter and use it in current control loop.
\end{DoxyItemize}

\DoxyHorRuler{0}
\hypertarget{md_icub-main_2src_2libraries_2icubmod_2embObjMotionControl_2YARP4__Velocity__Control__Guide_autotoc_md61}{}\doxysection{\texorpdfstring{1. Background}{1. Background}}\label{md_icub-main_2src_2libraries_2icubmod_2embObjMotionControl_2YARP4__Velocity__Control__Guide_autotoc_md61}
The original velocity-\/control implementation relied on a trajectory generator, commonly referred to as {\bfseries{Min\+Jerk}}. The input velocity reference was first processed by the trajectory generator before being passed to the subsequent control loops.

This implementation remains available and is referred to as the {\bfseries{standard}} or {\bfseries{classic velocity control}} mode.

The new architecture also supports direct control modes in which the trajectory generator is bypassed. This is useful when the user needs to send a velocity reference directly to the control loop without additional interpolation.

\DoxyHorRuler{0}
\hypertarget{md_icub-main_2src_2libraries_2icubmod_2embObjMotionControl_2YARP4__Velocity__Control__Guide_autotoc_md63}{}\doxysection{\texorpdfstring{2. Control Architecture}{2. Control Architecture}}\label{md_icub-main_2src_2libraries_2icubmod_2embObjMotionControl_2YARP4__Velocity__Control__Guide_autotoc_md63}
The control chain can be divided into two main levels\+:\hypertarget{md_icub-main_2src_2libraries_2icubmod_2embObjMotionControl_2YARP4__Velocity__Control__Guide_autotoc_md64}{}\doxysubsection{\texorpdfstring{High-\/level control}{High-\/level control}}\label{md_icub-main_2src_2libraries_2icubmod_2embObjMotionControl_2YARP4__Velocity__Control__Guide_autotoc_md64}
High-\/level controllers generally run at approximately 1 k\+Hz and include\+:


\begin{DoxyItemize}
\item Position control.
\item Velocity control.
\item Mixed position/velocity control.
\item Position Direct control.
\item Velocity Direct control.
\item The trajectory-\/generation stage, such as Min\+Jerk.
\end{DoxyItemize}\hypertarget{md_icub-main_2src_2libraries_2icubmod_2embObjMotionControl_2YARP4__Velocity__Control__Guide_autotoc_md65}{}\doxysubsection{\texorpdfstring{Low-\/level control}{Low-\/level control}}\label{md_icub-main_2src_2libraries_2icubmod_2embObjMotionControl_2YARP4__Velocity__Control__Guide_autotoc_md65}
Low-\/level controllers are implemented on the motor-\/control boards and include\+:


\begin{DoxyItemize}
\item PWM output.
\item Current control.
\item Velocity control.
\item Velocity control with an internal current loop.
\item Current limiting and motor-\/side feedback processing.
\end{DoxyItemize}

The final control law is selected through the motor-\/control configuration files. Different control schemes can be obtained by enabling or disabling branches of the general control structure and by configuring the corresponding PID parameters.

\hypertarget{md_icub-main_2src_2libraries_2icubmod_2embObjMotionControl_2YARP4__Velocity__Control__Guide_autotoc_md67}{}\doxysection{\texorpdfstring{3. Control Modes}{3. Control Modes}}\label{md_icub-main_2src_2libraries_2icubmod_2embObjMotionControl_2YARP4__Velocity__Control__Guide_autotoc_md67}
\hypertarget{md_icub-main_2src_2libraries_2icubmod_2embObjMotionControl_2YARP4__Velocity__Control__Guide_autotoc_md68}{}\doxysubsection{\texorpdfstring{3.\+1 Standard Position Control}{3.\+1 Standard Position Control}}\label{md_icub-main_2src_2libraries_2icubmod_2embObjMotionControl_2YARP4__Velocity__Control__Guide_autotoc_md68}
In standard position control, the position reference is processed by the trajectory generator. The generated trajectory is then used by the position controller.

The output of the position controller can be connected to different low-\/level control modes, such as\+:


\begin{DoxyItemize}
\item PWM.
\item Current.
\item Velocity.
\item Velocity with an internal current loop.
\end{DoxyItemize}

The trajectory generator is enabled in this mode.

\DoxyHorRuler{0}
\hypertarget{md_icub-main_2src_2libraries_2icubmod_2embObjMotionControl_2YARP4__Velocity__Control__Guide_autotoc_md70}{}\doxysubsection{\texorpdfstring{3.\+2 Position Direct Control}{3.\+2 Position Direct Control}}\label{md_icub-main_2src_2libraries_2icubmod_2embObjMotionControl_2YARP4__Velocity__Control__Guide_autotoc_md70}
Position Direct bypasses the trajectory generator.

The position reference is sent directly to the position controller. A velocity reference can also be sent together with the position reference and used as a feedforward term.

Position Direct can be combined with the following low-\/level outputs\+:


\begin{DoxyItemize}
\item PWM.
\item Current.
\item Velocity.
\item Velocity with an internal current loop.
\end{DoxyItemize}

The position-\/direct PID is already available on the EMS board. The associated PID parameters must be correctly exposed through the configuration protocol and YARP configuration pipeline.

\DoxyHorRuler{0}
\hypertarget{md_icub-main_2src_2libraries_2icubmod_2embObjMotionControl_2YARP4__Velocity__Control__Guide_autotoc_md72}{}\doxysubsection{\texorpdfstring{3.\+3 Standard Velocity Control}{3.\+3 Standard Velocity Control}}\label{md_icub-main_2src_2libraries_2icubmod_2embObjMotionControl_2YARP4__Velocity__Control__Guide_autotoc_md72}
Standard velocity control uses the trajectory generator. The velocity reference is interpolated before being sent to the velocity controller.

The velocity controller can generate\+:


\begin{DoxyItemize}
\item A PWM command.
\item A current reference.
\item A velocity reference for a lower-\/level velocity loop.
\item A velocity reference followed by the internal current loop.
\end{DoxyItemize}

This mode is intended to preserve compatibility with the existing control behavior.

\DoxyHorRuler{0}
\hypertarget{md_icub-main_2src_2libraries_2icubmod_2embObjMotionControl_2YARP4__Velocity__Control__Guide_autotoc_md74}{}\doxysubsection{\texorpdfstring{3.\+4 Velocity Direct Control}{3.\+4 Velocity Direct Control}}\label{md_icub-main_2src_2libraries_2icubmod_2embObjMotionControl_2YARP4__Velocity__Control__Guide_autotoc_md74}
{\bfseries{Velocity Direct}} is the main new YARP 4 control mode.

In this mode\+:


\begin{DoxyItemize}
\item The velocity reference is sent directly to the velocity controller.
\item The Min\+Jerk trajectory generator is bypassed.
\item The output can be configured as either\+:
\begin{DoxyItemize}
\item PWM, or
\item current.
\end{DoxyItemize}
\end{DoxyItemize}

The mode is intended for applications requiring direct velocity control on the motor-\/side.

The new YARP interface exposes the direct velocity command through a dedicated interface containing the {\ttfamily set\+Velocity} operation.

{\bfseries{In 2FOC case}}\+: The user configures the PID gains in machine-\/unit and velocity references have to be in metric unit.

The Velocity Direct mode is explicitly distinguished from the original velocity-\/control mode.

\DoxyHorRuler{0}
\hypertarget{md_icub-main_2src_2libraries_2icubmod_2embObjMotionControl_2YARP4__Velocity__Control__Guide_autotoc_md76}{}\doxysubsection{\texorpdfstring{3.\+5 Mixed Control}{3.\+5 Mixed Control}}\label{md_icub-main_2src_2libraries_2icubmod_2embObjMotionControl_2YARP4__Velocity__Control__Guide_autotoc_md76}
The Mixed mode accepts both position and velocity references.

The velocity reference can be used as a feedforward component while the position reference is processed by the position controller. The exact behavior depends on the motor-\/control configuration.

The existing YARP {\ttfamily MIXED} mode was considered for this purpose. However, the final control law must be defined explicitly at the configuration and firmware levels rather than relying only on the historical behavior of the interface.

\DoxyHorRuler{0}
\hypertarget{md_icub-main_2src_2libraries_2icubmod_2embObjMotionControl_2YARP4__Velocity__Control__Guide_autotoc_md78}{}\doxysection{\texorpdfstring{4. Low-\/\+Level Output Modes}{4. Low-\/\+Level Output Modes}}\label{md_icub-main_2src_2libraries_2icubmod_2embObjMotionControl_2YARP4__Velocity__Control__Guide_autotoc_md78}
The high-\/level controller can be connected to different low-\/level output stages.\hypertarget{md_icub-main_2src_2libraries_2icubmod_2embObjMotionControl_2YARP4__Velocity__Control__Guide_autotoc_md79}{}\doxysubsection{\texorpdfstring{4.\+1 PWM Output}{4.\+1 PWM Output}}\label{md_icub-main_2src_2libraries_2icubmod_2embObjMotionControl_2YARP4__Velocity__Control__Guide_autotoc_md79}
With PWM output, the controller directly generates a PWM command for the motor.

The current loop is not explicitly included in the configured control chain. However, the 2FOC board can still apply current limiting where required.

This mode is useful when the user needs direct torque-\/like actuation through PWM.

\DoxyHorRuler{0}
\hypertarget{md_icub-main_2src_2libraries_2icubmod_2embObjMotionControl_2YARP4__Velocity__Control__Guide_autotoc_md81}{}\doxysubsection{\texorpdfstring{4.\+2 Current Output}{4.\+2 Current Output}}\label{md_icub-main_2src_2libraries_2icubmod_2embObjMotionControl_2YARP4__Velocity__Control__Guide_autotoc_md81}
With current output, the high-\/level controller generates a current reference.

The current reference is then processed by the internal current loop on the 2FOC board. This provides a cascaded architecture in which the current controller regulates the motor current take into account the {\ttfamily Kbemf} paramter

This mode is useful when current regulation and torque control are required.

\DoxyHorRuler{0}
