\doxysubsection{Detailed Description}
Allowed parameter values (tokens) used for configuration file validation. 

This namespace contains the string constants representing the set of valid values that configuration parameters can assume. They are used by the parser to validate user-\/provided settings (e.\+g., control law type, feedback units, sensor type, axis type). These are NOT default values; for fallback defaults see the \doxylink{namespaceyarp_1_1dev_1_1eomc_1_1defaults}{defaults} namespace.
