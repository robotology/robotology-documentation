\doxysubsection{Detailed Description}
A legend item representing a plottable with an icon and the plottable name. 

This is the standard legend item for plottables. It displays an icon of the plottable next to the plottable name. The icon is drawn by the respective plottable itself (\doxylink{classQCPAbstractPlottable_a9a450783fd9ed539e589999fd390cdf7}{QCPAbstract\+Plottable\+::draw\+Legend\+Icon}), and tries to give an intuitive symbol for the plottable. For example, the \doxylink{classQCPGraph}{QCPGraph} draws a centered horizontal line and/or a single scatter point in the middle.

Legend items of this type are always associated with one plottable (retrievable via the \doxylink{classQCPPlottableLegendItem_abeaabdcfd9de2e0020c94321716e36ab}{plottable()} function and settable with the constructor). You may change the font of the plottable name with \doxylink{classQCPAbstractLegendItem_a409c53455d8112f71d70c0c43eb10265}{set\+Font}. Icon padding and border pen is taken from the parent \doxylink{classQCPLegend}{QCPLegend}, see \doxylink{classQCPLegend_a2f2c93d18a651f4ff294bb3f026f49b8}{QCPLegend\+::set\+Icon\+Border\+Pen} and \doxylink{classQCPLegend_a62973bd69d5155e8ea3141366e8968f6}{QCPLegend\+::set\+Icon\+Text\+Padding}.

The function QCPAbstract\+Plottable\+::add\+To\+Legend/ \doxylink{classQCPAbstractPlottable_ac95fb2604d9106d0852ad9ceb326fe8c}{QCPAbstract\+Plottable\+::remove\+From\+Legend} creates/removes legend items of this type in the default implementation. However, these functions may be reimplemented such that a different kind of legend item (e.\+g a direct subclass of \doxylink{classQCPAbstractLegendItem}{QCPAbstract\+Legend\+Item}) is used for that plottable.

Since \doxylink{classQCPLegend}{QCPLegend} is based on \doxylink{classQCPLayoutGrid}{QCPLayout\+Grid}, a legend item itself is just a subclass of \doxylink{classQCPLayoutElement}{QCPLayout\+Element}. While it could be added to a legend (or any other layout) via the normal layout interface, \doxylink{classQCPLegend}{QCPLegend} has specialized functions for handling legend items conveniently, see the documentation of \doxylink{classQCPLegend}{QCPLegend}.
