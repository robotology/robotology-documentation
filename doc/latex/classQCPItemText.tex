\doxysubsection{Detailed Description}
A text label. 



Its position is defined by the member {\itshape position} and the setting of \doxylink{classQCPItemText_a781cdf8c640fc6a055dcff1e675c8c7a}{set\+Position\+Alignment}. The latter controls which part of the text rect shall be aligned with {\itshape position}.

The text alignment itself (i.\+e. left, center, right) can be controlled with \doxylink{classQCPItemText_ab5bc0684c4d1bed81949a11b34dba478}{set\+Text\+Alignment}.

The text may be rotated around the {\itshape position} point with \doxylink{classQCPItemText_a4bcc10cd97952c3f749d75824b5077f0}{set\+Rotation}.

\doxysubsubsection{\texorpdfstring{selectTest()}{selectTest()}}
{\footnotesize\ttfamily double QCPItem\+Text\+::select\+Test (\begin{DoxyParamCaption}\item[{const QPointF \&}]{pos,  }\item[{bool}]{only\+Selectable,  }\item[{QVariant \texorpdfstring{$\ast$}{*}}]{details = {\ttfamily 0} }\end{DoxyParamCaption}) const\hspace{0.3cm}{\ttfamily [virtual]}}



This function is used to decide whether a click hits a layerable object or not. 

{\itshape pos} is a point in pixel coordinates on the \doxylink{classQCustomPlot}{QCustom\+Plot} surface. This function returns the shortest pixel distance of this point to the object. If the object is either invisible or the distance couldn\textquotesingle{}t be determined, -\/1.\+0 is returned. Further, if {\itshape only\+Selectable} is true and the object is not selectable, -\/1.\+0 is returned, too.

If the item is represented not by single lines but by an area like \doxylink{classQCPItemRect}{QCPItem\+Rect} or \doxylink{classQCPItemText}{QCPItem\+Text}, a click inside the area returns a constant value greater zero (typically the selection\+Tolerance of the parent \doxylink{classQCustomPlot}{QCustom\+Plot} multiplied by 0.\+99). If the click lies outside the area, this function returns -\/1.\+0.

Providing a constant value for area objects allows selecting line objects even when they are obscured by such area objects, by clicking close to the lines (i.\+e. closer than 0.\+99\texorpdfstring{$\ast$}{*}selection\+Tolerance).

The actual setting of the selection state is not done by this function. This is handled by the parent \doxylink{classQCustomPlot}{QCustom\+Plot} when the mouse\+Release\+Event occurs, and the finally selected object is notified via the select\+Event/deselect\+Event methods.

{\itshape details} is an optional output parameter. Every layerable subclass may place any information in {\itshape details}. This information will be passed to \doxylink{classQCPAbstractItem_aaf92af7b9893712959a6c073d334d88d}{select\+Event} when the parent \doxylink{classQCustomPlot}{QCustom\+Plot} decides on the basis of this select\+Test call, that the object was successfully selected. The subsequent call to \doxylink{classQCPAbstractItem_aaf92af7b9893712959a6c073d334d88d}{select\+Event} will carry the {\itshape details}. This is useful for multi-\/part objects (like \doxylink{classQCPAxis}{QCPAxis}). This way, a possibly complex calculation to decide which part was clicked is only done once in \doxylink{classQCPItemText_aca74494fd5e769f331a6eb3e29f32916}{select\+Test}. The result (i.\+e. the actually clicked part) can then be placed in {\itshape details}. So in the subsequent \doxylink{classQCPAbstractItem_aaf92af7b9893712959a6c073d334d88d}{select\+Event}, the decision which part was selected doesn\textquotesingle{}t have to be done a second time for a single selection operation.

You may pass 0 as {\itshape details} to indicate that you are not interested in those selection details.
