\doxysubsection{Detailed Description}
A derived class defining a first abstraction layer on top of \doxylink{group__ActionPrimitives}{action\+Primitives} father class. 

It internally predeclares (without actually defining) a set of hand sequence motions key ("{}open\+\_\+hand"{}, "{}close\+\_\+hand"{} and "{}karate\+\_\+hand"{} \+:) that are used for \doxylink{classiCub_1_1action_1_1ActionPrimitivesLayer1_a95ab2896f4f80d8ef01f12ffc1b8aa74}{grasp()}, \doxylink{classiCub_1_1action_1_1ActionPrimitivesLayer1_afaffe75f376d9b03053eee1ee62902ed}{touch()} and \doxylink{classiCub_1_1action_1_1ActionPrimitivesLayer1_a94b4da629121987844332c75d4d52300}{tap()} actions.

\begin{DoxyNote}{Note}
Given as an example of how primitive actions can be combined in higher level actions, thus how further layers can be inherited from the base class. 
\end{DoxyNote}
