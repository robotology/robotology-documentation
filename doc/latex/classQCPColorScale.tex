\doxysubsection{Detailed Description}
A color scale for use with color coding data such as \doxylink{classQCPColorMap}{QCPColor\+Map}. 

This layout element can be placed on the plot to correlate a color gradient with data values. It is usually used in combination with one or multiple \doxylink{classQCPColorMap}{QCPColor\+Maps}.



The color scale can be either horizontal or vertical, as shown in the image above. The orientation and the side where the numbers appear is controlled with \doxylink{classQCPColorScale_a1bf9bdb291927c422dd66b404b206f1f}{set\+Type}.

Use \doxylink{classQCPColorMap_aa828921db364fe3c6af4619580ab85fd}{QCPColor\+Map\+::set\+Color\+Scale} to connect a color map with a color scale. Once they are connected, they share their gradient, data range and data scale type (\doxylink{classQCPColorScale_a1f29583bb6f1e7f473b62fb712be3940}{set\+Gradient}, \doxylink{classQCPColorScale_abe88633003a26d1e756aa74984587fef}{set\+Data\+Range}, \doxylink{classQCPColorScale_aeb6107d67dd7325145b2498abae67fc3}{set\+Data\+Scale\+Type}). Multiple color maps may be associated with a single color scale, to make them all synchronize these properties.

To have finer control over the number display and axis behaviour, you can directly access the \doxylink{classQCPColorScale_a39bdbdb3b212602a5a57f9f3ea444190}{axis}. See the documentation of \doxylink{classQCPAxis}{QCPAxis} for details about configuring axes. For example, if you want to change the number of automatically generated ticks, call 
\begin{DoxyCode}{0}
\DoxyCodeLine{colorScale-\/>axis()-\/>setAutoTickCount(3);}

\end{DoxyCode}


Placing a color scale next to the main axis rect works like with any other layout element\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{\mbox{\hyperlink{classQCPColorScale}{QCPColorScale}}\ *colorScale\ =\ \textcolor{keyword}{new}\ \mbox{\hyperlink{classQCPColorScale}{QCPColorScale}}(customPlot);}

\end{DoxyCode}
 In this case we have placed it to the right of the default axis rect, so it wasn\textquotesingle{}t necessary to call \doxylink{classQCPColorScale_a1bf9bdb291927c422dd66b404b206f1f}{set\+Type}, since \doxylink{classQCPAxis_ae2bcc1728b382f10f064612b368bc18aadf5509f7d29199ef2f263b1dd224b345}{QCPAxis\+::at\+Right} is already the default. The text next to the color scale can be set with \doxylink{classQCPColorScale_aee124ae8396320cacf8276e9a0fbb8ce}{set\+Label}.

For optimum appearance (like in the image above), it may be desirable to line up the axis rect and the borders of the color scale. Use a \doxylink{classQCPMarginGroup}{QCPMargin\+Group} to achieve this\+:

Color scales are initialized with a non-\/zero minimum top and bottom margin (\doxylink{classQCPLayoutElement_a0a8a17abc16b7923159fcc7608f94673}{set\+Minimum\+Margins}), because vertical color scales are most common and the minimum top/bottom margin makes sure it keeps some distance to the top/bottom widget border.
