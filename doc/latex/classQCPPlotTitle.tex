\doxysubsection{Detailed Description}
A layout element displaying a plot title text. 

The text may be specified with \doxylink{classQCPPlotTitle_aae5a93e88050dfb2cbf6adc087516821}{set\+Text}, theformatting can be controlled with \doxylink{classQCPPlotTitle_a199fc7170802ea65006c371875349e37}{set\+Font} and \doxylink{classQCPPlotTitle_a71273e3a0ca6b4c151591b37b9e5ce33}{set\+Text\+Color}.

A plot title can be added as follows\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{customPlot-\/>plotLayout()-\/>insertRow(0);\ \textcolor{comment}{//\ inserts\ an\ empty\ row\ above\ the\ default\ axis\ rect}}
\DoxyCodeLine{customPlot-\/>plotLayout()-\/>addElement(0,\ 0,\ \textcolor{keyword}{new}\ \mbox{\hyperlink{classQCPPlotTitle}{QCPPlotTitle}}(customPlot,\ \textcolor{stringliteral}{"{}Your\ Plot\ Title"{}}));}

\end{DoxyCode}


Since a plot title is a common requirement, \doxylink{classQCustomPlot}{QCustom\+Plot} offers specialized selection signals for easy interaction with \doxylink{classQCPPlotTitle}{QCPPlot\+Title}. If a layout element of type \doxylink{classQCPPlotTitle}{QCPPlot\+Title} is clicked, the signal \doxylink{classQCustomPlot_a2137a819e518fee7edd1c0bf5984d8d6}{QCustom\+Plot\+::title\+Click} is emitted. A double click emits the \doxylink{classQCustomPlot_ad51d65f6abf5edfaeef6e0519a4c1a2f}{QCustom\+Plot\+::title\+Double\+Click} signal.
