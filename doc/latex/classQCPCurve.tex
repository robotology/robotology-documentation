\doxysubsection{Detailed Description}
A plottable representing a parametric curve in a plot. 



Unlike \doxylink{classQCPGraph}{QCPGraph}, plottables of this type may have multiple points with the same key coordinate, so their visual representation can have {\itshape loops}. This is realized by introducing a third coordinate {\itshape t}, which defines the order of the points described by the other two coordinates {\itshape x} and {\itshape y}.

To plot data, assign it with the \doxylink{classQCPCurve_a631ac886708460013b30052f49cbc9da}{set\+Data} or \doxylink{classQCPCurve_a4e24023c3b9ac75440c7a260172c99af}{add\+Data} functions.\hypertarget{classQCPStatisticalBox_appearance}{}\doxysubsection{\texorpdfstring{Changing the appearance}{Changing the appearance}}\label{classQCPStatisticalBox_appearance}
The appearance of the curve is determined by the pen and the brush (\doxylink{classQCPAbstractPlottable_ab74b09ae4c0e7e13142fe4b5bf46cac7}{set\+Pen}, \doxylink{classQCPAbstractPlottable_a7a4b92144dca6453a1f0f210e27edc74}{set\+Brush}). \hypertarget{classQCPStatisticalBox_usage}{}\doxysubsection{\texorpdfstring{Usage}{Usage}}\label{classQCPStatisticalBox_usage}
Like all data representing objects in \doxylink{classQCustomPlot}{QCustom\+Plot}, the \doxylink{classQCPCurve}{QCPCurve} is a plottable (\doxylink{classQCPAbstractPlottable}{QCPAbstract\+Plottable}). So the plottable-\/interface of \doxylink{classQCustomPlot}{QCustom\+Plot} applies (\doxylink{classQCustomPlot_a32de81ff53e263e785b83b52ecd99d6f}{QCustom\+Plot\+::plottable}, \doxylink{classQCustomPlot_ab7ad9174f701f9c6f64e378df77927a6}{QCustom\+Plot\+::add\+Plottable}, \doxylink{classQCustomPlot_af3dafd56884208474f311d6226513ab2}{QCustom\+Plot\+::remove\+Plottable}, etc.)

{\footnotesize\ttfamily double QCPCurve\+::select\+Test (\begin{DoxyParamCaption}\item[{const QPointF \&}]{pos,  }\item[{bool}]{only\+Selectable,  }\item[{QVariant \texorpdfstring{$\ast$}{*}}]{details = {\ttfamily 0} }\end{DoxyParamCaption}) const\hspace{0.3cm}{\ttfamily [virtual]}}



This function is used to decide whether a click hits a layerable object or not. 

{\itshape pos} is a point in pixel coordinates on the \doxylink{classQCustomPlot}{QCustom\+Plot} surface. This function returns the shortest pixel distance of this point to the object. If the object is either invisible or the distance couldn\textquotesingle{}t be determined, -\/1.\+0 is returned. Further, if {\itshape only\+Selectable} is true and the object is not selectable, -\/1.\+0 is returned, too.

If the item is represented not by single lines but by an area like \doxylink{classQCPItemRect}{QCPItem\+Rect} or \doxylink{classQCPItemText}{QCPItem\+Text}, a click inside the area returns a constant value greater zero (typically the selection\+Tolerance of the parent \doxylink{classQCustomPlot}{QCustom\+Plot} multiplied by 0.\+99). If the click lies outside the area, this function returns -\/1.\+0.

Providing a constant value for area objects allows selecting line objects even when they are obscured by such area objects, by clicking close to the lines (i.\+e. closer than 0.\+99\texorpdfstring{$\ast$}{*}selection\+Tolerance).

The actual setting of the selection state is not done by this function. This is handled by the parent \doxylink{classQCustomPlot}{QCustom\+Plot} when the mouse\+Release\+Event occurs, and the finally selected object is notified via the select\+Event/deselect\+Event methods.

{\itshape details} is an optional output parameter. Every layerable subclass may place any information in {\itshape details}. This information will be passed to \doxylink{classQCPAbstractPlottable_a16aaad02456aa23a759efd1ac90c79bf}{select\+Event} when the parent \doxylink{classQCustomPlot}{QCustom\+Plot} decides on the basis of this select\+Test call, that the object was successfully selected. The subsequent call to \doxylink{classQCPAbstractPlottable_a16aaad02456aa23a759efd1ac90c79bf}{select\+Event} will carry the {\itshape details}. This is useful for multi-\/part objects (like \doxylink{classQCPAxis}{QCPAxis}). This way, a possibly complex calculation to decide which part was clicked is only done once in \doxylink{classQCPCurve_a87a9fb34a2a48dcae4c1245ada235e7d}{select\+Test}. The result (i.\+e. the actually clicked part) can then be placed in {\itshape details}. So in the subsequent \doxylink{classQCPAbstractPlottable_a16aaad02456aa23a759efd1ac90c79bf}{select\+Event}, the decision which part was selected doesn\textquotesingle{}t have to be done a second time for a single selection operation.

You may pass 0 as {\itshape details} to indicate that you are not interested in those selection details.
