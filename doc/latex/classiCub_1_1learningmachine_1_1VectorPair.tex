\doxysubsection{Detailed Description}
A pair of vectors using the wire format formerly provided by yarp\+::os\+::\+Portable\+Pair$<$yarp\+::sig\+::\+Vector, yarp\+::sig\+::\+Vector$>$. 

Portable\+Pair was removed in YARP 4. Keeping the serialization local makes learning\+Machine compatible with both existing ports and recorded data.
