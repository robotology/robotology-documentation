\doxysubsection{Detailed Description}

This is a YARP device designed for {\ttfamily ergo\+Cub} and {\ttfamily \doxylink{namespaceiCub}{i\+Cub}} platforms that provides information about the accuracy of the joints calibration procedure. It helps collect and analyze data related to miscalibration errors on specific systems. The device interfaces with robot {\bfseries{control boards}} and {\bfseries{raw encoder data}} streams through YARP.

The device performs calibration checking by\+:
\begin{DoxyItemize}
\item Connecting to remote control boards and raw encoder data ports
\item Reading and comparing joint positions with expected golden positions (in degrees)
\item Analyzing calibration accuracy and generating detailed reports
\item Providing visual and numerical output for calibration analysis
\end{DoxyItemize}\hypertarget{dir_28dbe54e4325deb354fca60339688421_autotoc_md32}{}\doxysubsection{\texorpdfstring{Main Features}{Main Features}}\label{dir_28dbe54e4325deb354fca60339688421_autotoc_md32}
The main features of this device include\+:
\begin{DoxyItemize}
\item Configuration through XML files containing joint information and parameters
\item Integration with motion control and raw values publisher network wrappers
\item Remote control board connectivity for joint and encoder data access
\item Comparison of golden hard-\/stop positions with live encoder readings
\item Analysis of differences between expected and measured joint positions
\item Generation of CSV output files and optional visual feedback
\item Asynchronous operation as a threaded YARP device
\end{DoxyItemize}

This device helps developers and technicians verify and fine-\/tune the mechanical calibration of robot joints, ensuring accurate and reliable operation.\hypertarget{dir_28dbe54e4325deb354fca60339688421_autotoc_md33}{}\doxysubsection{\texorpdfstring{Configuration Parameters}{Configuration Parameters}}\label{dir_28dbe54e4325deb354fca60339688421_autotoc_md33}
