Available options are\+:

{\bfseries{robot}} $<$string$>$\+: example (robot icub), specifies the name of the robot to connect to.

{\bfseries{type}} $<$string$>$\+: example (type right), specifies the type of the limb to be instantiated; it can be "{}left"{} or "{}right"{}.

{\bfseries{dof}} \texorpdfstring{$<$}{<}(int int ...)\texorpdfstring{$>$}{>}\+: example (dof (1 1 0 1 ...)), specifies which dof of the chain are actuated (by putting 1 in the corresponding position) and which not (with 0). The length of the provided list of 1\textquotesingle{}s and 0\textquotesingle{}s should match the number of chain\textquotesingle{}s links. The special value 2 is used to keep the link status unchanged and proceed to the next link.

{\bfseries{rest\+\_\+pos}} \texorpdfstring{$<$}{<}(double double ...)\texorpdfstring{$>$}{>}\+: example (rest\+\_\+pos (20.\+0 0.\+0 0.\+0 ...)), specifies in degrees the joints rest position used as secondary task in the minimization. The length of the provided list should match the number of chain\textquotesingle{}s links. Default values are (0.\+0 0.\+0 0.\+0 ...).

{\bfseries{rest\+\_\+weights}} \texorpdfstring{$<$}{<}(double double ...)\texorpdfstring{$>$}{>}\+: example (rest\+\_\+weights (1.\+0 0.\+0 0.\+0 1.\+0 ...)), specifies for each link the weights used for the secondary task minimization. The length of the provided list should match the number of the chain\textquotesingle{}s links. Default values are (0.\+0 0.\+0 0.\+0 ...).

{\bfseries{period}} $<$int$>$\+: example (period 30), specifies the thread period in ms.

{\bfseries{pose}} $<$vocab$>$\+: example (pose full), specifies the end-\/effector pose the user wants to achieve; it can be \mbox{[}full\mbox{]} (position+orientation) or \mbox{[}xyz\mbox{]} (only position).

{\bfseries{mode}} \+: example (mode cont), selects the solver mode between \mbox{[}cont\mbox{]} which implements a continuous tracking and \mbox{[}shot\mbox{]} which does not compensate for movements induced on unacatuated joints.

{\bfseries{verbosity}} $<$vocab$>$\+: example (verbosity on), selects whether to report or not on the screen the result of each optimization instance; allowed values are \mbox{[}on\mbox{]} or \mbox{[}off\mbox{]}.

{\bfseries{tol}} $<$double$>$\+: example (tol 0.\+001), specifies the desired tolerance on the task function to be minimized.

{\bfseries{constr\+\_\+tol}} $<$double$>$\+: example (constr\+\_\+tol 0.\+000001), specifies the desired tolerance for the constraints to comply with.

{\bfseries{max\+Iter}} $<$int$>$\+: example (max\+Iter 200), specifies the maximum number of iterations allowed for one optimization instance.

{\bfseries{inter\+Points}} $<$vocab$>$\+: example (inter\+Points on), selects whether to force or not the solver to output on the port all intermediate points of optimization instance; allowed values are \mbox{[}on\mbox{]} or \mbox{[}off\mbox{]}.

{\bfseries{ping\+\_\+robot\+\_\+tmo}} $<$double$>$\+: example (ping\+\_\+robot\+\_\+tmo 2.\+0), specifies a timeout in seconds during which robot state ports are pinged prior to connecting; a timeout equal to zero disables this option.
