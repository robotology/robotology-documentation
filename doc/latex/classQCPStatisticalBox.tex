\doxysubsection{Detailed Description}
A plottable representing a single statistical box in a plot. 



To plot data, assign it with the individual parameter functions or use \doxylink{classQCPStatisticalBox_adf50c57b635edb12470c0e4a986aff37}{set\+Data} to set all parameters at once. The individual functions are\+: \begin{DoxyItemize}
\item \doxylink{classQCPStatisticalBox_a84ff7cc61ba44890f0c3e0c99c19941e}{set\+Minimum} \item \doxylink{classQCPStatisticalBox_a680941af5e23d902013962fa67223f9e}{set\+Lower\+Quartile} \item \doxylink{classQCPStatisticalBox_a65970e77a897da4ecb4b15300868aad3}{set\+Median} \item \doxylink{classQCPStatisticalBox_a65a1375f941c5a2077b5201229e89346}{set\+Upper\+Quartile} \item \doxylink{classQCPStatisticalBox_acec5ad1901f00f2c5387cfb4d9787eb3}{set\+Maximum}\end{DoxyItemize}
Additionally you can define a list of outliers, drawn as scatter datapoints\+: \begin{DoxyItemize}
\item \doxylink{classQCPStatisticalBox_af9bc09620e0bf93bf444ee35e5800d1d}{set\+Outliers}\end{DoxyItemize}
\hypertarget{classQCPStatisticalBox_appearance}{}\doxysubsection{\texorpdfstring{Changing the appearance}{Changing the appearance}}\label{classQCPStatisticalBox_appearance}
The appearance of the box itself is controlled via \doxylink{classQCPAbstractPlottable_ab74b09ae4c0e7e13142fe4b5bf46cac7}{set\+Pen} and \doxylink{classQCPAbstractPlottable_a7a4b92144dca6453a1f0f210e27edc74}{set\+Brush}. You may change the width of the box with \doxylink{classQCPStatisticalBox_a0b62775bd67301b1eba5c785f2b26f14}{set\+Width} in plot coordinates (not pixels).

Analog functions exist for the minimum/maximum-\/whiskers\+: \doxylink{classQCPStatisticalBox_a4a5034cb3b9b040444df05ab1684620b}{set\+Whisker\+Pen}, \doxylink{classQCPStatisticalBox_aa8d3e503897788e1abf68dc74b5f147f}{set\+Whisker\+Bar\+Pen}, \doxylink{classQCPStatisticalBox_adf378812446bd66f34d1f7f293d991cd}{set\+Whisker\+Width}. The whisker width is the width of the bar at the top (maximum) and bottom (minimum).

The median indicator line has its own pen, \doxylink{classQCPStatisticalBox_a7260ac55b669f5d0a74f16d5ca84c52c}{set\+Median\+Pen}.

If the whisker backbone pen is changed, make sure to set the cap\+Style to Qt\+::\+Flat\+Cap. Else, the backbone line might exceed the whisker bars by a few pixels due to the pen cap being not perfectly flat.

The Outlier data points are drawn as normal scatter points. Their look can be controlled with \doxylink{classQCPStatisticalBox_ad5241943422eb8e58360a97e99ad6aa7}{set\+Outlier\+Style}\hypertarget{classQCPStatisticalBox_usage}{}\doxysubsection{\texorpdfstring{Usage}{Usage}}\label{classQCPStatisticalBox_usage}

So the plottable-\/interface of \doxylink{classQCustomPlot}{QCustom\+Plot} applies (\doxylink{classQCustomPlot_a32de81ff53e263e785b83b52ecd99d6f}{QCustom\+Plot\+::plottable}, \doxylink{classQCustomPlot_ab7ad9174f701f9c6f64e378df77927a6}{QCustom\+Plot\+::add\+Plottable}, \doxylink{classQCustomPlot_af3dafd56884208474f311d6226513ab2}{QCustom\+Plot\+::remove\+Plottable}, etc.)

\doxysubsubsection{\texorpdfstring{selectTest()}{selectTest()}}
{\footnotesize\ttfamily double QCPStatistical\+Box\+::select\+Test (\begin{DoxyParamCaption}\item[{const QPointF \&}]{pos,  }\item[{bool}]{only\+Selectable,  }\item[{QVariant \texorpdfstring{$\ast$}{*}}]{details = {\ttfamily 0} }\end{DoxyParamCaption}) const\hspace{0.3cm}{\ttfamily [virtual]}}



This function is used to decide whether a click hits a layerable object or not. 

{\itshape pos} is a point in pixel coordinates on the \doxylink{classQCustomPlot}{QCustom\+Plot} surface. This function returns the shortest pixel distance of this point to the object. If the object is either invisible or the distance couldn\textquotesingle{}t be determined, -\/1.\+0 is returned. Further, if {\itshape only\+Selectable} is true and the object is not selectable, -\/1.\+0 is returned, too.

If the item is represented not by single lines but by an area like \doxylink{classQCPItemRect}{QCPItem\+Rect} or \doxylink{classQCPItemText}{QCPItem\+Text}, a click inside the area returns a constant value greater zero (typically the selection\+Tolerance of the parent \doxylink{classQCustomPlot}{QCustom\+Plot} multiplied by 0.\+99). If the click lies outside the area, this function returns -\/1.\+0.

Providing a constant value for area objects allows selecting line objects even when they are obscured by such area objects, by clicking close to the lines (i.\+e. closer than 0.\+99\texorpdfstring{$\ast$}{*}selection\+Tolerance).

The actual setting of the selection state is not done by this function. This is handled by the parent \doxylink{classQCustomPlot}{QCustom\+Plot} when the mouse\+Release\+Event occurs, and the finally selected object is notified via the select\+Event/deselect\+Event methods.

{\itshape details} is an optional output parameter. Every layerable subclass may place any information in {\itshape details}. This information will be passed to \doxylink{classQCPAbstractPlottable_a16aaad02456aa23a759efd1ac90c79bf}{select\+Event} when the parent \doxylink{classQCustomPlot}{QCustom\+Plot} decides on the basis of this select\+Test call, that the object was successfully selected. The subsequent call to \doxylink{classQCPAbstractPlottable_a16aaad02456aa23a759efd1ac90c79bf}{select\+Event} will carry the {\itshape details}. This is useful for multi-\/part objects (like \doxylink{classQCPAxis}{QCPAxis}). This way, a possibly complex calculation to decide which part was clicked is only done once in \doxylink{classQCPStatisticalBox_a0153ac16326b94450afbca208e3f9961}{select\+Test}. The result (i.\+e. the actually clicked part) can then be placed in {\itshape details}. So in the subsequent \doxylink{classQCPAbstractPlottable_a16aaad02456aa23a759efd1ac90c79bf}{select\+Event}, the decision which part was selected doesn\textquotesingle{}t have to be done a second time for a single selection operation.

You may pass 0 as {\itshape details} to indicate that you are not interested in those selection details.
