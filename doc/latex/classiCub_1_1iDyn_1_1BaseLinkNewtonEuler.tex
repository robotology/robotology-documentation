\doxysubsection{Detailed Description}
A class for setting a virtual base link\+: this is useful to initialize the forward phase of Newton-\/\+Euler\textquotesingle{}s method, by setting w, dw, ddp; H is an identity matrix, while ddpC=ddp; Note that this is a virtual link, since there\textquotesingle{}s no \doxylink{classiCub_1_1iDyn_1_1iDynLink}{i\+Dyn\+Link} attached\+: it is just necessary to make the recursive Newton-\/\+Euler computations.
