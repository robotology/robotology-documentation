\doxysubsection{Detailed Description}
A plottable representing a two-\/dimensional color map in a plot. 



The data is stored in the class \doxylink{classQCPColorMapData}{QCPColor\+Map\+Data}, which can be accessed via the \doxylink{classQCPColorMap_a047d7eb3ae657f93f2f39b5e68b79451}{data()} method.

A color map has three dimensions to represent a data point\+: The {\itshape key} dimension, the {\itshape value} dimension and the {\itshape data} dimension. As with other plottables such as graphs, {\itshape key} and {\itshape value} correspond to two orthogonal axes on the \doxylink{classQCustomPlot}{QCustom\+Plot} surface that you specify in the QColor\+Map constructor. The {\itshape data} dimension however is encoded as the color of the point at ({\itshape key}, {\itshape value}).

Set the number of points (or {\itshape cells}) in the key/value dimension via \doxylink{classQCPColorMapData_a0d9ff35c299d0478b682bfbcdd9c097e}{QCPColor\+Map\+Data\+::set\+Size}. The plot coordinate range over which these points will be displayed is specified via \doxylink{classQCPColorMapData_aad9c1c7c703c1339489fc730517c83d4}{QCPColor\+Map\+Data\+::set\+Range}. The first cell will be centered on the lower range boundary and the last cell will be centered on the upper range boundary. The data can be set by either accessing the cells directly with \doxylink{classQCPColorMapData_a8e75eaf8746596319032a93f3d2d0683}{QCPColor\+Map\+Data\+::set\+Cell} or by addressing the cells via their plot coordinates with \doxylink{classQCPColorMapData_afd2083ccfd6987ec94aa7ef8e91ca39a}{QCPColor\+Map\+Data\+::set\+Data}. If possible, you should prefer set\+Cell, since it doesn\textquotesingle{}t need to do any coordinate transformation and thus performs a bit better.

The cell with index (0, 0) is at the bottom left, if the color map uses normal (i.\+e. not reversed) key and value axes.

To show the user which colors correspond to which {\itshape data} values, a \doxylink{classQCPColorScale}{QCPColor\+Scale} is typically placed to the right of the axis rect. See the documentation there for details on how to add and use a color scale.\hypertarget{classQCPStatisticalBox_appearance}{}\doxysubsection{\texorpdfstring{Changing the appearance}{Changing the appearance}}\label{classQCPStatisticalBox_appearance}
The central part of the appearance is the color gradient, which can be specified via \doxylink{classQCPColorMap_a7313c78360471cead3576341a2c50377}{set\+Gradient}. See the documentation of \doxylink{classQCPColorGradient}{QCPColor\+Gradient} for details on configuring a color gradient.

The {\itshape data} range that is mapped to the colors of the gradient can be specified with \doxylink{classQCPColorMap_a980b42837821159786a85b4b7dcb8774}{set\+Data\+Range}. To make the data range encompass the whole data set minimum to maximum, call \doxylink{classQCPColorMap_a856608fa3dd1cc290bcd5f29a5575774}{rescale\+Data\+Range}.\hypertarget{classQCPStatisticalBox_usage}{}\doxysubsection{\texorpdfstring{Usage}{Usage}}\label{classQCPStatisticalBox_usage}

So the plottable-\/interface of \doxylink{classQCustomPlot}{QCustom\+Plot} applies (\doxylink{classQCustomPlot_a32de81ff53e263e785b83b52ecd99d6f}{QCustom\+Plot\+::plottable}, \doxylink{classQCustomPlot_ab7ad9174f701f9c6f64e378df77927a6}{QCustom\+Plot\+::add\+Plottable}, \doxylink{classQCustomPlot_af3dafd56884208474f311d6226513ab2}{QCustom\+Plot\+::remove\+Plottable}, etc.)

\begin{DoxyNote}{Note}
The \doxylink{classQCPColorMap}{QCPColor\+Map} always displays the data at equal key/value intervals, even if the key or value axis is set to a logarithmic scaling. If you want to use \doxylink{classQCPColorMap}{QCPColor\+Map} with logarithmic axes, you shouldn\textquotesingle{}t use the \doxylink{classQCPColorMapData_afd2083ccfd6987ec94aa7ef8e91ca39a}{QCPColor\+Map\+Data\+::set\+Data} method as it uses a linear transformation to determine the cell index. Rather directly access the cell index with \doxylink{classQCPColorMapData_a8e75eaf8746596319032a93f3d2d0683}{QCPColor\+Map\+Data\+::set\+Cell}. 
\end{DoxyNote}

This corresponds to the \doxylink{classQCPAbstractPlottable_ae96b83c961e257da116c6acf9c7da308}{rescale\+Key\+Axis} or \doxylink{classQCPAbstractPlottable_aa1e408bb2d13999150c3f7f8a8579ca9}{rescale\+Value\+Axis} methods, only for the third data dimension of the color map.

The minimum and maximum values of the data set are buffered in the internal \doxylink{classQCPColorMapData}{QCPColor\+Map\+Data} instance (\doxylink{classQCPColorMap_a047d7eb3ae657f93f2f39b5e68b79451}{data}). As data is updated via its \doxylink{classQCPColorMapData_a8e75eaf8746596319032a93f3d2d0683}{QCPColor\+Map\+Data\+::set\+Cell} or \doxylink{classQCPColorMapData_afd2083ccfd6987ec94aa7ef8e91ca39a}{QCPColor\+Map\+Data\+::set\+Data}, the buffered minimum and maximum values are updated, too. For performance reasons, however, they are only updated in an expanding fashion. So the buffered maximum can only increase and the buffered minimum can only decrease. In consequence, changes to the data that actually lower the maximum of the data set (by overwriting the cell holding the current maximum with a smaller value), aren\textquotesingle{}t recognized and the buffered maximum overestimates the true maximum of the data set. The same happens for the buffered minimum. To recalculate the true minimum and maximum by explicitly looking at each cell, the method \doxylink{classQCPColorMapData_ab235ade8a4d64bd3adb26a99b3dd57ee}{QCPColor\+Map\+Data\+::recalculate\+Data\+Bounds} can be used. This function is used to decide whether a click hits a layerable object or not. 

{\itshape pos} is a point in pixel coordinates on the \doxylink{classQCustomPlot}{QCustom\+Plot} surface. This function returns the shortest pixel distance of this point to the object. If the object is either invisible or the distance couldn\textquotesingle{}t be determined, -\/1.\+0 is returned. Further, if {\itshape only\+Selectable} is true and the object is not selectable, -\/1.\+0 is returned, too.

If the item is represented not by single lines but by an area like \doxylink{classQCPItemRect}{QCPItem\+Rect} or \doxylink{classQCPItemText}{QCPItem\+Text}, a click inside the area returns a constant value greater zero (typically the selection\+Tolerance of the parent \doxylink{classQCustomPlot}{QCustom\+Plot} multiplied by 0.\+99). Providing a constant value for area objects allows selecting line objects even when they are obscured by such area objects, by clicking close to the lines (i.\+e. closer than 0.\+99\texorpdfstring{$\ast$}{*}selection\+Tolerance).

The actual setting of the selection state is not done by this function. This is handled by the parent \doxylink{classQCustomPlot}{QCustom\+Plot} when the mouse\+Release\+Event occurs, and the finally selected object is notified via the select\+Event/deselect\+Event methods.
