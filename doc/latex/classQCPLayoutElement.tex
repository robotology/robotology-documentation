\doxysubsection{Detailed Description}
The abstract base class for all objects that form \doxysectlink{thelayoutsystem}{the layout system}{0}. 

This is an abstract base class. As such, it can\textquotesingle{}t be instantiated directly, rather use one of its subclasses.

A Layout element is a rectangular object which can be placed in layouts. It has an outer rect (\doxylink{classQCPLayoutElement_a2a32a12a6161c9dffbadeb9cc585510c}{QCPLayout\+Element\+::outer\+Rect}) and an inner rect (\doxylink{classQCPLayoutElement_a208effccfe2cca4a0eaf9393e60f2dd4}{QCPLayout\+Element\+::rect}). The difference between outer and inner rect is called its margin. The margin can either be set to automatic or manual (\doxylink{classQCPLayoutElement_accfda49994e3e6d51ed14504abf9d27d}{set\+Auto\+Margins}) on a per-\/side basis. If a side is set to manual, that margin can be set explicitly with \doxylink{classQCPLayoutElement_a8f450b1f3f992ad576fce2c63d8b79cf}{set\+Margins} and will stay fixed at that value. If it\textquotesingle{}s set to automatic, the layout element subclass will control the value itself (via \doxylink{classQCPLayoutElement_a005c9f0fe84bc1591a2cf2c46fd477b4}{calculate\+Auto\+Margin}).

Layout elements can be placed in layouts (base class \doxylink{classQCPLayout}{QCPLayout}) like \doxylink{classQCPLayoutGrid}{QCPLayout\+Grid}. The top level layout is reachable via \doxylink{classQCustomPlot_af1a1f1f571237deb7c2bd34a5e9f018f}{QCustom\+Plot\+::plot\+Layout}, and is a \doxylink{classQCPLayoutGrid}{QCPLayout\+Grid}. Since \doxylink{classQCPLayout}{QCPLayout} itself derives from \doxylink{classQCPLayoutElement}{QCPLayout\+Element}, layouts can be nested.

Thus in \doxylink{classQCustomPlot}{QCustom\+Plot} one can divide layout elements into two categories\+: The ones that are invisible by themselves, because they don\textquotesingle{}t draw anything. Their only purpose is to manage the position and size of other layout elements. This category of layout elements usually use \doxylink{classQCPLayout}{QCPLayout} as base class. Then there is the category of layout elements which actually draw something. For example, \doxylink{classQCPAxisRect}{QCPAxis\+Rect}, \doxylink{classQCPLegend}{QCPLegend} and \doxylink{classQCPPlotTitle}{QCPPlot\+Title} are of this category.
